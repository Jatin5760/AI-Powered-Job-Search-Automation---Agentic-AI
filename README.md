# AjenticAI - AI-Powered Job Search Automation 🤖💼

[![Workflow](https://img.shields.io/badge/N8N-Workflow-blue?logo=n8n)](#)

## Overview
AjenticAI automates the **job search process** using N8N, integrating **LinkedIn, Google Sheets, and Gmail APIs**. It reduces manual effort by **90%** by automatically extracting job postings, matching resumes using AI, generating cover letters, and notifying users via email.

This workflow is perfect for:
- Job seekers looking to **save time**.
- Learning **workflow automation with N8N**.
- Exploring **AI-powered resume–job matching**.

---

## 🔹 Features
- Automatic extraction of **LinkedIn job postings** (200+ per day)  
- AI-driven **resume–job matching** with match scores (0–100)  
- Automatic **cover letter generation** using Google Gemini (PaLM)  
- Data structured in **Google Sheets** for easy tracking  
- Scheduled **email notifications** with new job alerts  

---

## 🛠️ Tools & Technologies
- **N8N** – Workflow automation platform  
- **JavaScript** – Custom scripts in workflow nodes  
- **Google Gemini API** – AI for matching resumes and generating cover letters  
- **Google Sheets API** – Store structured data  
- **Gmail API** – Send automatic email notifications  

---

## ⚡ How to Use
1. Import the `AjenticAI_Workflow.json` in your **N8N instance**  
2. Configure API credentials:
   - LinkedIn API  
   - Google Sheets API  
   - Gmail API  
   - Google Gemini API (PaLM)  
3. Activate the workflow and schedule it to run **daily**  
4. Watch automated job postings appear in your Google Sheet and receive notifications  

---

## 💡 Notes
- Ensure **API keys and credentials** are secure  
- This workflow can be **extended** to other job portals like Indeed, Glassdoor, etc.  
- Modify Google Sheet template as per your preference
